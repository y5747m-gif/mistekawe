# MISTEKAWE

## مجلس الصوت

الصفحة الرئيسية تطبيق لتشغيل الصوت على **عدة سماعات أو أي مخرج بلوتوث معًا**
دون قطع. ثمانية وكلاء محليون (بلا أي خدمة ذكاء خارجية) ينسّقون الربط، الساعة،
العزف، والمزج.

```bash
python3 server/serve.py      # http://localhost:8000/
```

* **ربط بلوتوث:** إذن المتصفح، الاسم، البطارية، وإعادة الاتصال. هذا الرابط لا يحمل الصوت، فسقوطه لا يقطعه.
* **مخرج لكل سماعة:** `setSinkId` على مسار Web Audio مستقل. إضافة سماعة تلحق باللحظة الحالية ولا تعيد تشغيل البقية.
* **بلا فجوة:** المقطع التالي يُجدول على خيط الصوت قبل النهاية. انحراف صغير يُمتص بتأخير ناعم، وتجمّد التبويب يُرجع الساعة بدل إعادة التشغيل.
* الاختبارات: `node tests/node/sound-tests.mjs`

المتجر التراثي بقي في `heritage.html` و`shop.html`. استوديو 3D في `studio.html`.

## استوديو AI 3D

مستودع يجمع بين متجر إلكتروني (ننجاوي) و**استوديو AI 3D** لتحويل الصور إلى
نماذج ثلاثية الأبعاد.

## استوديو AI IMAGE TO 3D

مدخل الاستوديو: `studio.html` — محرك إعادة بناء ثلاثي الأبعاد محلي ومستقل:

```
IMAGE → ANALYSIS → DETECTION → SEGMENTATION → DEPTH → POINT CLOUD
      → TSDF RECONSTRUCTION → MESH → UV ATLAS → TEXTURE/MATERIALS
      → OPTIMIZATION → VIEWER → EXPORT
```

* **لا يعتمد على أي خدمة ذكاء اصطناعي خارجية** (لا OpenAI/ChatGPT ولا خدمة تحويل جاهزة).
* كل المعالجة تتم على جهاز المستخدم داخل المتصفح، والصور لا تغادر الجهاز.
* تصدير: GLB • glTF • OBJ+MTL • STL • PLY • ZIP (مع الخرائط وتقرير JSON).

### التشغيل السريع

```bash
python3 server/serve.py      # http://localhost:8000/studio.html
```

### الاختبارات (بدون متصفح)

```bash
node tests/node/run-tests.mjs
```
