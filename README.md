## أكاديمية رحيق — منصة تسجيل الدخول (قيد التحويل)

### منصة رحيق RAHEEQ — تسجيل ولي الأمر (`raheeq.html`)

صفحة واحدة كاملة (HTML + CSS + JS داخلي، بلا خادم) — عربي RTL بالكامل:

```bash
python3 server/serve.py      # ثم افتح http://localhost:8000/raheeq.html
```

* **تسجيل بـ 3 خطوات:** ولي الأمر (الاسم رباعي، الرقم القومي 14 رقمًا، صلة القرابة،
  الموبايل 11 رقمًا، واتساب، الإيميل، كلمة السر وتأكيدها) ← الطالب (الاسم رباعي،
  تاريخ الميلاد، النوع، الصف من KG1 إلى 3 ثانوي، المدرسة السابقة، العنوان، ملاحظات
  صحية) ← المستندات (شهادة الميلاد، صورة شخصية، بطاقة ولي الأمر، بيان نجاح،
  الموافقة على الشروط).
* **تسجيل دخول تجريبي** بالموبايل + كلمة السر، والحساب محفوظ في `LocalStorage`
  على الجهاز نفسه فقط، وليس نظام حسابات آمنًا أو مشتركًا بين الأجهزة.
* **أنميشن بداية الموقع:** يبدأ الموقع بشاشة ترحيبية يطوف فيها شعار رحيق في
  منتصف الشاشة ثم ينفجر في جزيئات بألوان الهوية ليظهر الموقع بسلاسة (مع زر
  «تخطي» ودعم تقليل الحركة).
* **تصميم مريح وبسيط بدمج اللون الأبيض:** بطاقة التسجيل وقسم «لماذا رحيق؟»
  وحاويات الشعار والصور تأتي باللون الأبيض النقي `#FFFFFF` متناغمًا مع البرغندي
  والكريمي والذهبي.
* **شاشة نجاح** برقم طلب `RHQ-XXXX` وعرض مصغرات الصور الفعلية المرفوعة،
  ورسالة «هنتواصل معاك خلال 24–48 ساعة».
* **سحب الصور الفعلية وإرسالها مع رسالة واتساب (`01151947735`):**
  لا يكتفي الموقع بأسماء الملفات؛ بل يسحب الصور الفعلية ويعرض معاينتها ويُعدّ
  ملفاتها الفعلية بالإضافة إلى بطاقة صور مجمّعة (PNG):
  * على الجوال والمتصفحات الداعمة لـ Web Share Files: يفتح مشاركة الصور الفعلية
    مع نص الرسالة مباشرة إلى واتساب.
  * على الحاسوب / واتساب ويب: ينسخ بطاقة الصور الفعلية للحافظة (`Ctrl+V`)
    ويفتح محادثة **01151947735** بالرسالة كاملة جاهزة (مع أزرار حفظ/نسخ مباشرة).

## مجلس الصوت — واجهة بسيطة + تطبيق APK للهاتف

مجلس الصوت يشغّل الصوت على **عدة سماعات في الوقت نفسه**. صار الآن سهلًا:
واجهة من ثلاث خطوات في المتصفح، وتطبيق **APK أصلي** للهاتف يفعلها فعلًا.

### تحميل التطبيق على الهاتف (APK)

1. افتح رابط التحميل من الهاتف:
   **https://github.com/y5747m-gif/mistekawe/releases/latest**
2. نزّل الملف `majlis-debug.apk` وثبّته (اسمح بـ «تثبيت من مصادر غير معروفة» عند الطلب).
3. افتح التطبيق واتبع الخطوات الثلاث الظاهرة على الشاشة.

> **لماذا APK وليس رابط ويب؟**
> المتصفح على الهاتف (وحتى تطبيق ويب داخل APK) لا يملك صلاحية إرسال الصوت
> إلى أكثر من سماعة بلوتوث؛ تبقى السماعة الثانية صامتة. التطبيق الأصلي يفتح
> **مسار صوت مستقل (AudioTrack) لكل سماعة** ويوجّهه بـ `setPreferredDevice`،
> فتعمل كل السماعات المفعّلة معًا، ويستمر التشغيل والشاشة مطفأة.

كود التطبيق في مجلد `android/`، ويُبنى تلقائيًا إلى APK عبر GitHub Actions
عند أي تعديل (`.github/workflows/build-apk.yml`).

```bash
cd android && gradle :app:assembleDebug    # بناء يدوي (JDK 17 + Android SDK)
```

### الواجهة البسيطة في المتصفح

```bash
python3 server/serve.py      # http://localhost:8000/
```

* `index.html` — الواجهة البسيطة: **أضف مخرجًا ← فعّله ← اضغط تشغيل**.
* `hall.html` — الوضع المتقدم (الوكلاء الثمانية، المعايرة، الانحراف).

خطوات التشغيل على الحاسوب:

1. اربط السماعات من إعدادات النظام كالمعتاد.
2. اضغط **إضافة سماعة / مخرج صوت** واختر كل سماعة مرة واحدة
   (أو **إضافة الباقي تلقائيًا** بعد أول اختيار).
3. اضغط **تشغيل**.

* **بلا فجوة:** المقطع التالي يُجدول على خيط الصوت قبل النهاية، وتجمّد
  التبويب يُرجع الساعة بدل إعادة التشغيل.
* **لا يُرسل صوت ولا اسم جهاز إلى أي خادم.** الحساب كله على جهازك.
* الاختبارات: `node tests/node/sound-tests.mjs`

المتجر التراثي في `heritage.html` و`shop.html`. استوديو 3D في `studio.html`.

## استوديو AI 3D

مستودع يجمع بين متجر إلكتروني (ننجاوي) و**استوديو AI 3D** لتحويل الصور إلى
نماذج ثلاثية الأبعاد.

## استوديو AI IMAGE TO 3D

مدخل الاستوديو: `studio.html` — محرك إعادة بناء ثلاثي الأبعاد محلي ومستقل:

```
IMAGE → ANALYSIS → DETECTION → SEGMENTATION → DEPTH → POINT CLOUD
      → TSDF RECONSTRUCTION → MESH → UV ATLAS → TEXTURE/MATERIALS
      → OPTIMIZATION → VIEWER → EXPORT
```

* **لا يعتمد على أي خدمة ذكاء اصطناعي خارجية** (لا OpenAI/ChatGPT ولا خدمة تحويل جاهزة).
* كل المعالجة تتم على جهاز المستخدم داخل المتصفح، والصور لا تغادر الجهاز.
* تصدير: GLB • glTF • OBJ+MTL • STL • PLY • ZIP (مع الخرائط وتقرير JSON).
