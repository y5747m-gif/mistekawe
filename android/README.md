# تطبيق أندرويد — مجلس الصوت (ننجاوي)

تطبيق أندرويد أصلي (Kotlin) يشغّل الصوت على **أكثر من سماعة بلوتوث في الوقت نفسه**.

## لماذا تطبيق أصلي وليس متصفحًا؟

المتصفح (وحتى تطبيق ويب داخل APK) لا يستطيع توجيه الصوت إلا إلى مخرج واحد،
لذلك تبقى السماعة الثانية صامتة. التطبيق الأصلي يفتح **مسار صوت مستقل
(AudioTrack) لكل سماعة** ويوجّه كل مسار بـ `setPreferredDevice` إلى جهاز بلوتوث
بعينه. النتيجة: كل السماعات التي تفعّلها تعزف معًا.

## طريقة العمل

1. `OutputScanner` يقرأ مخارج الصوت من `AudioManager` ويعرضها بأسمائها.
2. `MultiAudioEngine` يفكّ ترميز الملف مرة واحدة (MediaExtractor + MediaCodec).
3. نفس العيّنات تُكتب إلى كل مسار. كل مسار يُبدأ بصمت قصير يعوّض فرق التأخير،
   فتصل السماعات معًا. إضافة سماعة أثناء التشغيل تلتحق باللحظة نفسها دون إعادة
   تشغيل البقية.
4. `PlayerService` يبقي التشغيل حيًا عند إطفاء الشاشة.

## البناء

يُبنى تلقائيًا على GitHub Actions (`.github/workflows/build-apk.yml`) عند أي
تغيير داخل `android/`. للبناء يدويًا:

```bash
cd android
gradle :app:assembleDebug     # يحتاج JDK 17 وحزمة أندرويد SDK
```

الملف الناتج: `android/app/build/outputs/apk/debug/app-debug.apk`

## المتطلبات على الهاتف

* أندرويد 6 (API 23) فأعلى.
* إذن «الأجهزة القريبة / البلوتوث» لعرض أسماء السماعات (يُطلب مرة واحدة).
* السماعات تُربط من إعدادات الهاتف كالمعتاد، ثم تُفعَّل من داخل التطبيق.
