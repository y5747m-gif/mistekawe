# أصوات منصة رحيق RAHEEQ

ملفات الصوت المستخدمة في **الموقع** (`index.html` + `js/sounds.js` + `js/intro.js`) — تُحمّل مسبقًا عند فتح
الصفحة وتُشغَّل عند التفاعل فقط (متوافقة مع الجوال، بدون أي مكتبة خارجية):

| الملف | الاستخدام | مستوى الصوت |
|---|---|---|
| `click.mp3` | كل ضغطة زر وتبديل تبويب | 0.3 |
| `hover.mp3` | لمسة خفيفة عند المرور على أي زر أو بطاقة | 0.1 |
| `typing.mp3` | نقرة لوحة مفاتيح خفيفة أثناء الكتابة في أي حقل | 0.05 |
| `success.mp3` | نغمة نجاح عند التسجيل أو الدخول | 0.6 |
| `error.mp3` | طنين قصير عند فشل التحقق | 0.5 |
| `step.mp3` | صوت انسيابي عند التنقل بين الخطوات 1 ← 2 ← 3 | 0.4 |
| `upload.mp3` | صوت فرقعة عند رفع ملف | 0.4 |
| `toggle.mp3` | صوت مفتاح عند التبديل بين الدخول والتسجيل | 0.3 |
| `intro.wav` | whoosh سينمائي عند بدء عرض البداية (انيميشن الدخول) | 0.58 |
| `chime.wav` | رنين ملكي عند قمة العرض (تجميع الشعار) | 0.56 |

* الملفات الآن **MP3 حقيقية** (مشفّرة بـ LAME) بعد أن كانت بيانات WAV بامتداد `.mp3`،
  لضمان التشغيل على سفاري والجوال أيضًا.
* `intro.wav` و`chime.wav` ملفات WAV حقيقية (22050Hz، أحادي، 16-bit) مصنوعة بمعالجة صوتية رقمية:
  `intro.wav` = تصاعد نغمي + هفيف متصاعد (1.65 ثانية، ~71KB)، و`chime.wav` = رنين
  متلألئ بصدى ناعم (2.05 ثانية، ~88KB).
* `js/sounds.js` يحمّل الملفات العشرة عند بدء الصفحة عبر عناصر `Audio` ويكشف تشفيرها
  إلى `AudioBuffer` عبر Web Audio API، ولو تعذّر أي ملف يولّد النغمة تلقائيًا كمولّد احتياطي.
* زر 🔊 / 🔇 في الهيدر يحفظ التفضيل في `localStorage` تحت المفتاح `raheeq_sound`
  (الافتراضي: الصوت يعمل). الاهتزاز: `navigator.vibrate(100)` عند النجاح،
  و`[100, 50, 100]` عند الخطأ.

## عرض البداية: طبقات صوتية متزامنة

بالإضافة إلى الملفين الأساسيين، يولّد `js/sounds.js` أربع طبقات صوتية فورية عبر Web Audio API
تُشغَّل من `js/intro.js` في توقيت محسوب مع حركة المشهد:

| الطبقة | متى تُشغَّل | الأثر |
|---|---|---|
| `bar` | مع صعود كل عمود بياني (4 نغمات: D4 → F#4 → A4 → D5) | إحساس بالتصاعد خطوة بخطوة |
| `shard` | لحظة تجمّع شظايا الشعار | هفيف ذهبي متلألئ |
| `sparkle` | عند ظهور «رحيق / RAHEEQ» | بريق نغمي صاعد |
| `curtain` | لحظة انكشاف الموقع | نسمة ختامية ناعمة |

* الجدول الزمني: `whoosh` عند 140ms ← أعمدة عند 360/500/640/760ms ← `shard` عند 1080ms
  ← `chime` عند 2540ms ← `sparkle` عند 2900ms ← `curtain` عند 4540ms.
* لو منع المتصفح التشغيل التلقائي قبل أول لمسة، `catchUpSfx` يلتقط أول تفاعل ويُشغّل
  الطبقات المتبقية متزامنة مع موضع المشهد الحالي بدل تشغيلها متأخرة.
* زر `.intro-sound-btn` داخل العرض يوضّح حالة الصوت بموجات متحركة (`.intro-eq`) وتُترجم
  نصوصه: `تشغيل الصوت` / `صوت العرض` / `الصوت` — وهو متزامن مع زر الصوت في الهيدر.
* زر «🎬 إعادة عرض البداية» في قائمة الجوال يستدعي `window.RaheeqIntro.replay()`.
* كل شيء يحترم `prefers-reduced-motion`: يتحوّل العرض إلى لقطة سريعة برنين واحد.

> لاستبدالها بأصوات حقيقية: ضع ملفات MP3 بنفس الأسماء في هذا المجلد وستعمل فورًا
> دون أي تعديل في الكود.
