# أصوات منصة رحيق RAHEEQ

ملفات الصوت المستخدمة في `raheeq.html` — تُحمّل عند فتح الصفحة وتُشغَّل عند التفاعل فقط (متوافقة مع الجوال):

| الملف | الاستخدام | مستوى الصوت |
|---|---|---|
| `click.mp3` | كل ضغطة زر وتبديل تبويب | 0.3 |
| `hover.mp3` | لمسة خفيفة عند المرور على زر أو بطاقة | 0.1 |
| `typing.mp3` | نقرة لوحة مفاتيح خفيفة أثناء الكتابة | 0.05 |
| `success.mp3` | نغمة نجاح عند التسجيل أو الدخول | 0.6 |
| `error.mp3` | طنين قصير عند فشل التحقق | 0.5 |
| `step.mp3` | صوت انسيابي عند التنقل بين الخطوات | 0.4 |
| `upload.mp3` | صوت فرقعة عند رفع ملف | 0.4 |
| `toggle.mp3` | صوت مفتاح عند التبديل بين الدخول والتسجيل | 0.3 |

> الملفات الحالية مولّدة محليًا كبداية. لاستبدالها بأصوات حقيقية:
> ضع ملفات MP3 بنفس الأسماء في هذا المجلد وستعمل فورًا دون أي تعديل في الكود.
> لو تعذّر تشغيل ملف، يولّد الكود الصوت تلقائيًا عبر Web Audio API كبديل.
