# أصوات منصة رحيق RAHEEQ

ملفات الصوت المستخدمة في **الموقع** (`index.html` + `js/sounds.js` + `js/intro.js`) — تُحمّل مسبقًا عند فتح
الصفحة وتُشغَّل عند التفاعل فقط (متوافقة مع الجوال، بدون أي مكتبة خارجية):

| الملف | الاستخدام | مستوى الصوت |
|---|---|---|
| `click.mp3` | كل ضغطة زر وتبديل تبويب | 0.3 |
| `hover.mp3` | لمسة خفيفة عند المرور على أي زر أو بطاقة | 0.1 |
| `typing.mp3` | نقرة لوحة مفاتيح خفيفة أثناء الكتابة في أي حقل | 0.05 |
| `success.mp3` | نغمة نجاح عند التسجيل أو الدخول | 0.6 |
| `error.mp3` | طنين قصير عند فشل التحقق | 0.5 |
| `step.mp3` | صوت انسيابي عند التنقل بين الخطوات 1 ← 2 ← 3 | 0.4 |
| `upload.mp3` | صوت فرقعة عند رفع ملف | 0.4 |
| `toggle.mp3` | صوت مفتاح عند التبديل بين الدخول والتسجيل | 0.3 |
| `intro.wav` | whoosh عند بدء عرض البداية (انيميشن الدخول) | 0.5 |
| `chime.wav` | رنين عند قمة العرض (تجميع الشعار) | 0.45 |

* الملفات الآن **MP3 حقيقية** (مشفّرة بـ LAME) بعد أن كانت بيانات WAV بامتداد `.mp3`،
  لضمان التشغيل على سفاري والجوال أيضًا.
* `js/sounds.js` يحمّل الملفات الثمانية عند بدء الصفحة عبر عناصر `Audio` ويكشف تشفيرها
  إلى `AudioBuffer` عبر Web Audio API، ولو تعذّر أي ملف يولّد النغمة تلقائيًا كمولّد احتياطي.
* زر 🔊 / 🔇 في الهيدر يحفظ التفضيل في `localStorage` تحت المفتاح `raheeq_sound`
  (الافتراضي: الصوت يعمل). الاهتزاز: `navigator.vibrate(100)` عند النجاح،
  و`[100, 50, 100]` عند الخطأ.

> لاستبدالها بأصوات حقيقية: ضع ملفات MP3 بنفس الأسماء في هذا المجلد وستعمل فورًا
> دون أي تعديل في الكود.
